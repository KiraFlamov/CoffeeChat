# @coffeechat/web

Веб-клиент: React, TypeScript, Vite, Tailwind. На этапе 0 в нём одна страница «Состояние системы».

## Запуск

```
task dev        # база, миграции, сервер и Vite; страница — http://localhost:5173
task dev:web    # только Vite, если сервер уже запущен
```

## Адреса API

Адреса сервера подставляются при сборке из переменных, в исходниках их нет.

| Переменная     | Что это         |
| -------------- | --------------- |
| `VITE_API_URL` | адрес HTTP API  |
| `VITE_WS_URL`  | адрес WebSocket |

- Локальные значения лежат в `.env.development`.
- Свой порт на ПК: файл `.env.development.local` с теми же переменными (в репозиторий не попадает) и переменная `ADDR` у сервера.
- Сборка (`task build:web`) без этих переменных падает с ошибкой.

## Что где

| Путь             | Содержимое                                                           |
| ---------------- | -------------------------------------------------------------------- |
| `src/checks/`    | проверки: клиент WebSocket, порядок проверок, подключение к браузеру |
| `src/strings.ts` | все тексты интерфейса (на этапе 1 заменит i18n)                      |
